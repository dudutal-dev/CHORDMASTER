## מה זה עושה

מציג את **האקורד הנכון ברגע הנכון**, מתחילת השיר ועד סופו, מעל סרטון יוטיוב מוטמע — עם דיאגרמת אצבעות, מילים מסונכרנות, האטה והעברת טונים.

## העיקרון

כל מה שרץ על המסך הוא פונקציה של `player.getCurrentTime()` — שעון הנגן של יוטיוב. **אין טיימר פנימי, אין `setInterval` שמקדם אקורדים, ואין אנימציית CSS שרצה בנפרד.** זו הסיבה שהתצוגה לא יכולה להתפצל מהשיר: עצירה, קפיצה אחורה או האטה ל־50% פשוט מזיזים את אותו שעון יחיד.

רשת הזמן היא פונקציה **לינארית־למקטעים** של עוגנים שהמשתמש מקיש, עם שיערוך טמפו ב**ריבועים פחותים** להשלמה מעבר לעוגן האחרון.

## דיוק שנמדד

מול שיר סינתטי עם דריפט טמפו ריאלי (±3%) ורעידת יד אנושית של 30 מ״ש:

| צפיפות ההקשה בכיול | סטייה ממוצעת | סטייה מרבית |
|---|---:|---:|
| כל מידה, לאורך כל השיר | 15 מ״ש | 30 מ״ש |
| כל 2 מידות | 12 מ״ש | 46 מ״ש |
| **כל 4 מידות** (ברירת מחדל) | **15 מ״ש** | **144 מ״ש** |
| כל 8 מידות | 26 מ״ש | 372 מ״ש |
| 24 מידות בהתחלה בלבד | 2,738 מ״ש | 6,026 מ״ש |

**המסקנה שמעצבת את הכלי:** עוגנים פרושים על כל השיר מנצחים בסדר גודל הקשות צפופות בהתחלה. האפליקציה מסמנת במסגרת מקווקוות כל מידה שמעבר לעוגן האחרון, ומציגה אחוז כיסוי.

## ספר השירים

59 שירי רוק וגרסאות אקוסטיות מקובלות (1963–1980) + 5 תבניות הרמוניות (בלוז 12 מידות, מיקסולידי I–bVII–IV, אאולי i–bVI–bVII, בס יורד). כל ערך כולל מהלך אקורדים, מבנה סקציות, סולם, קאפו והערת ניגון.

ל-29 מהערכים יש **קישור יוטיוב רשמי מאומת** — פתיחה בלחיצה אחת. לאחד מהם יש גם **קליפ מילים רשמי**, שנפתח ישירות במצב קליפ ומייתר את הדבקת המילים כליל. לשאר יש קישור חיפוש. קישורים נמחקים ונחסמים להטמעה עם הזמן — האפליקציה תמיד מאפשרת להדביק קישור חלופי.

**מה לא נכלל, במכוון:** מילים, הקלטות ומזהי וידאו. מהלך אקורדים הוא עובדה פונקציונלית; כל השאר מוגן או משתנה. הערכים הם הגרסאות המקובלות — אקורד למידה — ולא תמלול של ההקלטה.

## מסך הפתיחה

הגיטרה היא **מודל תלת־ממד שנבנה מאפס, בלי שום ספרייה**: מתאר גוף דו־ממדי שנמשך לעומק, הקרנה בפרספקטיבה, מיון פאות לפי עומק והצללה לפי זווית האור. ששת המיתרים הם **גלים עומדים מחושבים פר־פריים** — כל מיתר הוא סכום של הרמוניה בסיסית והרמוניה שנייה, עם מעטפת דעיכה מעריכית. מעבר אצבע פורט מיתר בתמונה ובצליל.

הצליל **מסונתז ולא מוקלט**: Karplus-Strong (רעש בקו השהיה באורך מחזור הצליל, ממוצע נע בכל סיבוב) → WaveShaper לעיוות → סינון → דיליי. אין בפרויקט שום קובץ שמע.

בכניסה מתנגנת פרזת גיטרה בת כ-7 שניות: מהלך מלווה במינור, ומעליו קול ליד עם **בנדים** (הזזת קצב הדגימה מגובה ההתחלה אל היעד), **ויברטו** (LFO על ה-detune) ו**סאסטיין ארוך**. המנגינה נכתבה לכלי הזה ואינה ציטוט של הקלטה קיימת.

דיוק הגובה שנמדד: כל ששת המיתרים בתוך **±4 סנט** מהתדר התקני.

## יכולות

- **מסך פתיחה קולנועי** — גיטרה בתנועת תלת־ממד שעוקבת אחרי האצבע, שלושה סיבובים מלאים בכניסה, וריף מסונתז שממשיך אל תוך האפליקציה
- **רקע ייעודי לכל מסך** — תמונה עמומה מתחת לשכבה כהה, שונה לספרייה, להגדרות, למדריך ולאודות

- **ספר שירים מוטמע** — 49 ערכים (כולל ישראלי: משינה, ברי סחרוף ודודו טסה) שנטענים מוכנים ללוח המידות, חלקם עם קישור רשמי מאומת
- **חיפוש יוטיוב מוטמע** — התוצאה הראשונה נטענת בתוך האפליקציה, עם דילוג לתוצאה הבאה ואישור בלחיצה
- **תמונות אמנים** — עטיפות אלבום נטענות משירות החיפוש הפתוח של אפל, עם מטמון מקומי ומתג כיבוי
- **מיון** א→ת / ת→א בספרייה
- **קטלוג מאוחד** — הספר המובנה, ספר האקורדים המיובא והשירים ששמרת, במקום אחד; רשימת אמנים עם מונה, וחיפוש בו־זמנית בשם השיר ובשם האמן
- **ייבוא ספר אקורדים אישי (PDF)** — נסרק בדפדפן בלבד, פעם אחת; האקורדים נשמרים מקומית ולכן הקובץ לא נדרש שוב. הקובץ עצמו לא נשמר ולא נכנס לפרויקט
- **הדבקה מאתר אקורדים** — מדביקים דף אקורדים כמו שהוא; הפרסר מסנן מילים ומחלץ את המהלך, כולל תמיכה בספרי אקורדים עבריים שבהם האקורדים כתובים מימין לשמאל
- **מצב קליפ מילים** — הווידאו גדול והאקורדים מתחתיו; שלב יישור המילים נמחק
- **מסלול אקורדים נע** — האקורדים הבאים זורמים לעבר קו ההווה, כל בלוק ברוחב אורכו בפועל
- **דיאגרמת יד אנטומית** — כף יד ואצבעות מעוקלות עם מספור, ברה כאצבע שוכבת; 24 אקורדים
- **מילים** שהמשתמש מדביק, מיושרות בהקשה, עם האקורדים מעל כל שורה
- **האטה** ל־75% / 50% בשמירת הגובה
- **העברת טונים** ±6 חצאי טונים עם כתיב נכון לפי הסולם
- **הצעת קאפו** אוטומטית — מוצאת את הקאפו שמייצר מרב אקורדים פתוחים
- **תיקון נקודתי** בהקשה אחת, בלי לכייל מחדש
- **ספרייה מקומית** + ייצוא JSON
- **מדריך מובנה** מלא באפליקציה
- **PWA** — ניתן להתקנה במסך הבית
- **זיהוי פרסומות** — הסנכרון קופא אוטומטית בזמן פרסומת וחוזר לבד, ויש גם הקפאה ידנית
- **פריסת נייד נעולה** — הווידאו ופס האקורדים נשארים בראש המסך, השאר נגלל מתחתיהם
- **אפס תלויות** — אין npm, אין באנדלר, אין פריימוורק

## הפעלה

```bash
git clone https://github.com/YOUR_USERNAME/play-along.git
cd play-along
python3 -m http.server 8000
# http://localhost:8000
```

פתיחה ישירה של `index.html` מהדיסק עובדת גם היא, אך הגשה דרך שרת מקומי אמינה יותר מול נגן יוטיוב.

## פרסום ב-GitHub Pages

1. העלה את כל הקבצים, **כולל התיקייה המוסתרת `.github/`**
2. Settings → Pages → Source: **GitHub Actions**
3. כל דחיפה ל־`main` מפרסמת אוטומטית

## עיצוב

**כיוון:** אפליקציית מוזיקה — קנבס שחור, מדפים אופקיים, וכרטיסי עטיפה. הזהות מהמגבר נשמרת בגוון הטונגסטן היחיד ובמנורת הפיילוט שמהבהבת על הדאונביט.

```css
--tolex:    #08090C   /* שחור — רקע */
--panel:    #14171C   /* משטח */
--edge:     #252A33   /* קנט */
--cream:    #EDEFF3   /* טקסט */
--tungsten: #F5B24A   /* צבע הדגשה */
--ruby:     #F2685A   /* אזהרה */
--jade:     #5FD0A8   /* אישור */
--violet:   #8A7BF0   /* הילה */
```

**עטיפות נוצרות מהשם:** לכל אמן ושיר יש כרטיס עם גרדיאנט שנגזר מגיבוב השם עצמו — אותו אמן מקבל תמיד את אותם גוונים, וכל אמן שונה מהאחר. אין בפרויקט אף קובץ תמונה.

**טיפוגרפיה:** `Suez One` לכותרות ואקורדים · `Heebo` לגוף · `Space Mono` לנתונים ותוויות.

## מגבלות ידועות

- **אין זיהוי אקורדים אוטומטי.** יוטיוב חוסם גישה לאודיו מוצלב־מקור, ולכן ניתוח ההקלטה בדפדפן אינו אפשרי. האקורדים מוזנים פעם אחת לשיר ונשמרים.
- **מז'ור ומינור בלבד** בתצוגת האצבעות.
- **העברת טונים משנה את המוצג ולא את הנשמע.**
- סרטונים שבעל הזכויות חסם להטמעה לא ייטענו.

## זכויות יוצרים

הכלי **אינו כולל ואינו מוריד** מילות שיר, אקורדים מסחריים או הקלטות. הווידאו מוגש מנגן יוטיוב הרשמי; המילים מודבקות על ידי המשתמש ונשמרות ב-`localStorage` במכשיר שלו בלבד.
